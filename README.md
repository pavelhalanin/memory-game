# Memory game

## How to run

1. Install [Git](https://git-scm.com/install)
1. Install [NodeJS](https://nodejs.org/en/download)
1. Clone repository
    ```
    git clone https://github.com/pavelhalanin/memory-game.git
    cd memory-game
    ```
1. Start locale serve
    ```
    npx serve -l 1234
    ```
1. Open on browser: http://localhost:1234
1. Enjoy
